# CLASS 管理画面 UI 正本 — 2026-11-28
2026-11-28にユーザーが選んだ4パネルの入口を今後の実装基準とする。
- 設計：事業・コース・クラス。既存の事業ツリー、初回作成ウィザード、コース内容・料金、開催枠。
- 募集：入会・イベント。既存の公開ページ、入会フロー、イベント、講習会、16問の改善。
- 運営：生徒・出欠・開催予定。既存の入会対応、名簿、欠席連絡、開催予定、イベント・講習会受付（募集と共通コンポーネント）。
- 会計：月謝・入金・売上。コース料金の参照、既存の差額入金確認・記録、販売・売上への導線。未実装の月次請求・集計は準備中と明記。
- 事業設定・契約・利用枠：事業名・呼称、選択事業に固定したCLASS B契約、販売・決済への導線。
ホームは4パネル2列、緑の線画アイコン、操作文字16px・タップ44px以上を目安。事業の選択は共通。下層ではCLASSホームへの戻り導線。旧5タブと開設/運営切替を初期入口から撤去。従来の保存API・権限・SSOTを変更しない。会計の月謝自動請求、一般販売、QR受付の本番開放はこのUI改修で有効化しない。
プレビューは実データと接続する可能性があるため画面・導線の確認に限定。実データを保存・公開・入金操作しない。既存データの変更・削除、DBマイグレーション、本番デプロイなし。

## 2026-11-28 利用者の仕事による再整理（承認済み）
- 新規事業の開設、既存事業の商品構成の変更、日常運営を区別。事業一覧は独立画面とし、選択後は事業名と「戻る」のみ表示。1事業でも一覧から選ぶ。新規作成後は設計に進む。
- 提供サービスは継続コース、短期講習会（複数開催回）、イベントの3種。クラスはコース内の開催枠。構成図に実データを表示し、作成ボタン4つは色付き図の外に置く。
- コース単体の作成と開催枠の追加を分離。コース未登録時のみ従来の初回クラス作成ガイドを使用し、複数コースがある場合は追加先を選択する。
- イベント・講習会は設計で下書き保存、募集で公開・受付終了・告知、運営で参加者と出欠を管理。同じAPIと既存コンポーネントを使用。受付終了した企画は構成図の履歴に表示。受付終了とサービス廃止は同一ではない。
- コース・クラスの廃止（契約・在籍者・振替・予約との整合を含む）は未実装。削除機能を仮実装しない。

## 共通移動と呼称設定（2026-11-28）
- CLASSホームの4パネルを維持し、各下層画面に設計・募集・運営・会計の共通タブを常設する。
- 事業設定でコース、クラス、短期講習会、イベントの表示名を設定可能とする。既存の役割呼称とは独立し、事業単位の既存JSONB設定に service_ 接頭辞で保存する。未設定は標準名称。内部分類・契約・上限・料金は不変。今回の反映範囲は管理ホーム・構成図・主要作成ボタン・募集と運営の入口・コースとイベント編集の主要ラベル。旧画面、公開ページ、メール、すべての説明文への適用は今後の課題。旧本番の役割呼称保存処理は新キーを保持しないため、プレビュー中は実事業への保存を行わない。
