## Ongoing workflow

The root `AGENTS.md` defines the source and deployment workflow.
Before work, fetch origin and run:

```sh
git fetch --prune origin
npm run repo:status
```

`repo:status` reads local refs; it does not fetch or inspect Vercel automatically.
Use `--check` to require clean work, no missing main commits and matching remote branch HEAD (or a main-equivalent checkout).
After independently reading Vercel production metadata, optionally pass its full SHA:

```sh
npm run repo:status -- --check --production-sha <full-production-commit-sha>
```

Use Git history instead of source backup copies. PR CI runs `npm run check:repo-hygiene` to prevent tracked snapshots and TypeScript caches from returning.
