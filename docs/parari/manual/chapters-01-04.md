# PARARI はじめての作品づくり ― 第1〜4章

短い文章と写真をひとつの作品にまとめ、URLで読んでもらうところまで進めます。練習には、日記、自己紹介、教室の案内など、短い題材をひとつ選んでください。写真は後から追加してもかまいません。

> **この原稿の確認状態**：2026年11月1日に現行mainの実装と照合しました。ブラウザーでの実操作は未確認です。「実画面で確認が必要」とした箇所は、操作・表示を確認してから説明を確定します。

## 第1章：会員登録とプランの選び方

### 到達目標

メールでPARARIにログインし、自分の作品を管理する場所と、現在のプランを確認できるようになります。第4章までの練習はFreeの利用範囲を前提に進めます。

### 操作手順

#### 1. ログイン用メールを受け取る

1. PARARIのトップページで「ログイン・登録」を押します。ログイン画面のパスは `/login` です。
2. 「Email」に、受信できるメールアドレスを入力します。
3. 「ログイン用メールを送る」を押します。パスワードの入力・作成欄はありません。
4. 「メールを送信しました」と表示されたら、表示されているメールアドレスを確認します。
5. 受信箱を開き、届いたメールのログイン用リンクを開きます。新しいタブでPARARIが開くことがあります。

メールが見つからなければ、迷惑メールフォルダも確認してください。「再送は ○ 秒後」の間は待ち、必要なら「もう一度送る」を押します。再送待ちは60秒です。入力を間違えた場合は「メールアドレスを修正する」で戻れます。

> **実画面で確認が必要**：初めてのメールアドレスでの登録成立、実際のメールの件名・差出人・リンクの表記、リンクを開いた後の画面。実装には登録とログインを共通で行うメール認証がありますが、初回登録の可否には稼働環境の認証設定も関係します。メール内のボタン名はこの原稿では指定しません。

#### 2. 作品の管理画面を開く

1. ログイン後、自分の作品一覧 `/my/works` を開きます。
2. 「今すぐ書く」「＋ 新規作成」があることを確認します。

ここが作品を作成・管理するSTUDIO側の入口です。通常ログイン後のトップページは、起動画面の保存済み設定がなければ作品一覧へ進む実装です。以前の設定や、別のページからのログインでは行き先が異なることがあります。別の画面に着いた場合も、同じPARARIサイトの `/my/works` を開いて進められます。

#### 3. 現在のプランを確認する

1. 設定の「プラン」タブを開きます。直接開く場合のパスは `/billing` です。
2. 「プランとお支払い」のページで「現在のプラン」を確認します。
3. 「現在適用されているプラン」に表示された名称を読みます。

新しく無料で始める場合はFreeの範囲で作品づくりを進めます。有料申込の操作は、この練習には必要ありません。

| 比較項目 | Free | Plus |
| --- | --- | --- |
| 月額表示 | $0 | $3 / month |
| 独立したPAGE・WEBの作成上限 | 合計10作品 | 合計100作品 |
| 公開作品 | 3作品まで | 100作品まで |
| 1 PAGEの本文文字数 | 20,000字まで | 50,000字まで |
| 画像保存容量の表示 | 100MB | 1GB |
| EPUB出力 | なし | EPUB3出力あり |

PAGEは内容のひとまとまりで、閲覧時に画面へ表示される紙面の枚数とは異なります。まずは独立したPAGEを1作品作ります。BOOKへのまとめ方は、この第1〜4章では扱いません。

> **実画面で確認が必要**：設定へ入るメニューの見え方、初回アカウントのFree表示、プラン・容量の実際の適用。表は現行のプラン画面と定義から転記しています。料金・上限が変わる可能性があるため、利用時は画面の表示も確認してください。BOOKの上限など、この練習に不要な詳細は省略しています。

### 結果の確認方法

- メールのリンクを開いた後、作品一覧を利用できることを確認します。
- 「現在のプラン」がエラーや読み込み中ではなく、プラン名を表示していることを確認します。
- ログインに失敗した場合は、表示された内容を確認します。「セッションが見つかりません（リンク期限切れの可能性）」と表示されたら、ログイン画面からメールを送り直して試します。

## 第2章：最初の一歩

### 到達目標

タイトルと短い本文を書き、必要なら写真を添えます。保存した作品を作品一覧から開き直せるようになります。

### 操作手順

#### 1. 白紙の作品を書き始める

1. 作品一覧で「今すぐ書く」を押します。
2. 新しい作品の画面が開いたら「Writing」を選びます。
3. 「＋ タイトル」を押し、「タイトル」欄に題名を入力します。練習例は「今日の小さな発見」です。
4. 本文の入力部分を押し、2〜3文を書きます。例えば「散歩の途中で、新しい喫茶店を見つけました。窓際の席から見える木がきれいでした。」と入力します。
5. 入力を止め、保存が終わるまで待ちます。

本文の入力部分が見つからない場合は、いったん「Editing」を押してください。本文が空の場合の入力欄の位置・カーソルの入り方は、実画面で確認が必要です。

「＋ 新規作成」から始める方法もあります。その場合は「新規作成」画面で「Page作品を作る」を選び、最初のタイトル「新しいPAGE」と本文「本文を書いてください。」を自分の内容に置き換えます。この章では、どちらか一方の入口で1作品だけ作れば十分です。

> **公開範囲について**：新規作品は初期設定が「限定公開」です。URLを知っている人が読める扱いなので、秘密の下書き用設定ではありません。他の人に読まれない状態で作業したい場合は、最初の保存後に「作品一覧」へ戻り、対象作品の公開設定を「非公開」に変更してください。操作の詳しい説明は第4章にあります。非公開作品の作者本人による「表示」の可否は実画面で確認が必要です。

#### 2. 写真を添える（任意）

1. Writing画面下部の「画像」を押します。
2. 端末から使いたい写真を1枚選びます。
3. 写真が表示されたら、画像の外を押し、保存を待ちます。

この「画像」は、作品の冒頭に配置する画像です。本文の途中に画像を入れる操作は第3章で説明します。冒頭の画像を取り外す場合は「画像を外す」を使います。

> **実画面で確認が必要**：端末の写真選択画面、アップロード完了、画像の向きや表示範囲、容量制限時の表示。冒頭画像の「画像を外す」は、保存容量を空けるための画像ファイル削除としては説明しません。

#### 3. 保存と表示を確かめる

1. 入力後、少し待ちます。実装では最後の変更から約0.9秒後に自動保存を開始します。通信にかかる時間は別に必要です。
2. PCなど、幅のある画面では上部の「保存中…」が「保存済み」になることを確認します。
3. 上部の「表示」を押し、読者用の表示でタイトル・本文・写真を確認します。確認後は、ブラウザーの戻る操作などで編集画面へ戻ります。
4. 保存後に「作品一覧」へ戻り、対象作品の「続きを書く」を押して、本文が残っているか確認します。

「今すぐ書く」では、本文などの内容が入って初めて作品を保存する実装です。タイトルだけでは保存されません。白紙のまま閉じた作品が一覧に残るとは限りません。「表示」も最初の作品保存前は使えない実装です。

保存状態の文字は、幅の狭い画面では非表示になる実装です。スマートフォンでは「保存済み」が必ず見えるとは説明できません。本文を別の場所にも控えたうえで、作品一覧から開き直して保存結果を確認してください。スマートフォンでの保存確認導線は実画面で確認が必要です。

保存エラーや「ログインを確認できませんでした。」が出た場合、保存が完了したと判断せず、入力内容を手元に控えてからログイン状態や通信を確認してください。

### 結果の確認方法

- 作品一覧に作品があり、「続きを書く」で自分の本文を開き直せます。
- 「表示」で練習用のタイトル・本文・写真を確認できます。ただし「非公開」にした作品の閲覧可否は別途確認が必要です。
- テンプレートを使った場合は、最初のサンプル本文を自分の文章に置き換えられています。

## 第3章：パネルでレイアウトする

### 到達目標

文章の間に画像やリストを加え、内容が読み取りやすい作品にします。必要なパネルを選び、表示を確かめられるようになります。

### 操作手順

#### 1. Editingへ切り替える

1. 第2章の作品を開き、上部の「Editing」を押します。作品一覧にある対象作品の「Editing」から直接開く方法もあります。
2. 「パネルセット」が表示されている場合は「標準」を選びます。「Kindle出版用」は第9章で扱います。
3. 追加したい位置の「＋」を押します。このボタンの説明は「パネルを追加」です。

Writingは文章を書くとき、Editingはパネルを追加したり設定を変えたりするときに使います。PCではCtrlキーを単独で押して離すと切り替わる実装ですが、まず画面のボタンを使ってください。

パネルが見出しだけで閉じている場合、クリックすると内容の表示が開き、次のクリックで編集へ進む実装です。「編集」ボタンが出ている場合はそれを使えます。パネルごとの開き方やスマートフォンのタップ操作は実画面で確認が必要です。

#### 2. 本文の後ろに画像を入れる

1. 本文の後ろの「＋」を押します。
2. メニューの「画像」を選びます。
3. 追加された画像パネルを編集できる状態にし、「＋ 画像を選ぶ」を押します。
4. 写真を選び、必要なら「キャプション」に説明を書きます。
5. 入力欄の外を押して変更を反映し、自動保存を待ちます。
6. 「表示」で、本文と画像の順序、写真の向き、説明文を確認します。

画像パネルの「設定」には「画像URL」「画像リンクURL」もあります。最初の作品では、写真選択とキャプションだけで進められます。

#### 3. 要点をリストにする

1. リストを置きたい位置の「＋」を押します。
2. 「パネル」から「リスト」を選びます。
3. 「リストのタイトル（任意）」に、例えば「覚えておきたいこと」と入力します。
4. 各項目に短い文章を入力します。「＋ 項目」で項目を増やせます。
5. 入力欄の外を押して変更を反映し、自動保存を待ちます。
6. 「表示」で、箇条書きになっていることと、内容が読みやすいことを確認します。

#### 4. 必要に応じてほかのパネルを使う

最初から全部使う必要はありません。追加メニューの名称と用途は次のとおりです。

| 「＋」からの選択 | 使いどころ |
| --- | --- |
| 文章 | 本文を追加する |
| 画像 | 本文の間に写真や図を入れる |
| パネル → お知らせ | 大事な案内をタイトルと本文でまとめる |
| パネル → リスト | 要点を箇条書きにする |
| パネル → 表 | 日程や料金などを行と列で整理する |
| パネル → ボタン | リンク先へ進むボタンを置く |
| パネル → 開閉 | 見出しを押して補足説明を開く |
| パネル → リンク | 複数のリンクをまとめる |
| パネル → QA | 問題・回答・解説などを用意する |
| メディア → YouTube | YouTubeの動画を配置する |
| メディア → 音声 | 音声URLを使って再生部分を配置する |

「表」を試す場合は、セルに内容を入力し、必要なら「下に行を追加」「右に列を追加」を使います。「先頭行を見出しにする」で見出し行を設定できます。「お知らせ」には「タイトル」「本文を入力」、「開閉」には「見出し」「本文を入力」の欄があります。

音声・YouTubeは、公開後に読者側で再生できるかも確かめてください。音声ファイルをこのメニューから直接アップロードできるとは説明していません。

> **実画面で確認が必要**：追加メニューの位置・展開方向、各パネルの編集の開き方、入力欄から離れた後の保存、ボタン・リンク先の設定と動作、開閉・QA・メディアの読者側動作。表に挙げた名称は追加メニューの実装と照合していますが、操作試験は未実施です。動画用の別実装はありますが、この追加メニューに「VIDEO／動画」は見つからないため、独立した動画パネルを追加する手順は記載しません。「Instagram」「カルーセル」など、今回の練習に不要な項目は省略しています。

### 結果の確認方法

1. 「Writing」に戻り、文章を続けて入力できることを確かめます。
2. 入力欄の外を押して保存を待ち、「表示」でタイトル・本文・画像・リストの順序を確かめます。
3. 編集用のラベルや入力欄ではなく、読者が読む内容を確認します。
4. 作品一覧から開き直し、追加したパネルと入力内容が残っていることを確認します。

## 第4章：作品を公開してURLを共有する

### 到達目標

作品の公開範囲を選び、読者用URLをコピーして共有します。自分がログインしていない状態でも読めることを確認して、無料公開を完了します。

### 操作手順

#### 1. 公開範囲を選ぶ

1. 編集を終え、各入力欄の外を押してから自動保存を待ちます。
2. 「作品一覧」へ戻ります。
3. 対象作品の「非公開」「限定公開」「公開」を選ぶ欄を確認します。現在の選択が表示されています。

| 選択肢 | このマニュアルでの使い方 |
| --- | --- |
| 非公開 | 一般向けのURL共有を止めたいとき。作者自身の表示や購入者など特別な閲覧権限は別途確認が必要です。 |
| 限定公開 | URLを伝えて読んでもらうとき。パスワードや招待者だけに制限する設定ではありません。 |
| 公開 | 一般公開するとき。選択時に一般公開の確認が出ます。 |

「限定公開」は、URLを知っている人が読める扱いです。秘密情報を守る機能として使わないでください。「公開」と「限定公開」で作者の公開一覧・検索などへの掲載がどう変わるかは、実画面で確認が必要です。

#### 2. 一般公開する

1. 対象作品の公開設定から「公開」を選びます。
2. 「この作品を一般公開しますか？」と、誰でも閲覧できるようになる旨の確認が出ます。内容を読み、公開する場合は確認を確定します。確定・取消ボタンの表記はブラウザーによって異なります。
3. 処理が終わり、選択が「公開」になっていることを確認します。
4. 作品一覧を開き直しても「公開」が維持されることを確認します。

URLを伝える相手に読んでもらう形でよければ、「限定公開」を選んで次へ進む方法もあります。一般公開を完了する練習では「公開」を選びます。

「公開設定を変更できませんでした。」や利用上限のメッセージが出た場合、変更が成功したとは判断しません。Freeの公開作品枠は3作品です。上限に達したときは、画面の案内を確認し、公開する作品を見直してください。現行のサーバー実装は「公開」への変更時に公開枠を確認し、公開作品数は公開フラグで数えます。「限定公開」だけの作品はこの計数に含めません。実環境での上限適用は確認が必要です。

#### 3. 読者用URLをコピーする

1. 対象作品の「表示」を押して、共有したい作品であることを確認します。
2. 作品一覧に戻り、その作品の「URL」を押します。
3. 「コピー済」と表示されたら、メールやLINEなどの入力欄に貼り付けます。
4. コピーできない場合は「このURLをコピーしてください」という画面に出たURLを手動でコピーします。

「URL」でコピーするのは、利用中のPARARIサイトのアドレスに `/p/作品ID` が続く読者用URLです。`/writing/…` などの編集用URLを共有しないよう、貼り付けた文字列を確認してください。「URL」の操作だけでは公開設定は変わりません。

#### 4. ログインしていない状態で確認してから送る

1. コピーしたURLを、PARARIにログインしていない別のブラウザーやプライベートブラウズで開きます。
2. タイトル・本文・画像が表示され、最後まで読めることを確認します。
3. リンク・開閉・メディアを使った作品は、その動作も確認します。
4. 読めることを確認したURLを、相手へ送信します。SNS・ブログなどにも同じURLを掲載できます。

作品が開けないときは、URLの貼り間違い、公開設定、保存・公開時のエラーを確認してください。作者がログインした画面で開けただけでは、読者が読める確認は完了していません。

### 結果の確認方法

- 作品一覧を開き直しても、選んだ公開設定が維持されています。
- ログインしていない状態で、共有用URLから作品を読めます。
- 共有するURLは `/p/作品ID` の読者用URLです。
- 本文・写真に誤りがなく、使ったリンクなども機能しています。

ここまでで無料公開は完了です。作品を直すときは、作品一覧の「続きを書く」または「Editing」から開き、保存後に同じ共有URLで更新結果を確かめます。すでに共有した作品の編集内容が読者へ反映されるタイミングは、実環境で確認が必要です。

作品を販売したい人は第5章へ進みます。PARARI販売を選ぶ場合は第6〜8章、Kindle出版を選ぶ場合は第9〜10章へ進む構成です。無料公開だけで利用を続ける場合は、ここで終えてかまいません。
